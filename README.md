# l10n-lint

Linter for localization files (.po, .ts). Find missing translations, placeholder mismatches, and common errors.

Built with Python CLI. Part of the [Danne L10n Suite](https://github.com/yeager/debian-repo).

## Installation

### Debian/Ubuntu
```bash
sudo apt install l10n-lint
```

### Fedora/RPM
```bash
sudo dnf install l10n-lint
```
